# 💰 Money Flow Tracker

# 📖 Overview

Money Flow Tracker is a modern personal finance management web application developed using **HTML, CSS, JavaScript and Supabase**.

It allows users to securely manage their income, expenses, savings, emergency funds and financial goals through a clean and interactive dashboard.

The application also provides analytics, charts, smart financial insights and cloud synchronization.
